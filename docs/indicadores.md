# Ficha de indicadores

Cada indicador se registra con tres niveles de evidencia, de mayor a menor peso: fuente oficial, organización civil, trabajo de campo y prensa. Un evento puntual (marcador) siempre lleva fecha, lugar, fuente y nivel de verificación. Un indicador agregado (círculos por entidad) siempre lleva periodo, unidad y fecha de corte.

## Ficha de verificación para eventos de prensa

Cada nota periodística que alimente un marcador se registra con: medio, fecha de publicación, URL o archivo, cita textual del dato, segunda fuente que lo confirma (si existe), y nivel asignado. Sin segunda fuente el evento queda como "prensa"; con confirmación oficial pasa a "oficial".
